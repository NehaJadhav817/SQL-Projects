# SQL Commands and Clauses

## Project Overview
This project demonstrates the use of SQL commands and clauses to create and manage database tables, insert records, retrieve data, filter results, sort records, perform calculations, and modify database structures.

The project uses four tables: Employee, Department, Product, and Sales. These tables are used to demonstrate SQL queries and database operations.

## Tools Used
- MySQL
- SQL
- Microsoft Excel

## Project Files
- **SQL-Commands-and-Clauses-Documentation.xlsx:** Contains the SQL questions and table structures.
- **SQL-Commands-and-Clauses.sql:** Contains the SQL queries and their solutions.

## Database Tables
- **Employee:** Stores employee IDs, names, departments, salaries, and gender.
- **Department:** Stores department IDs, department names, and locations.
- **Product:** Stores product IDs, product names, prices, stock quantities, and employee references.
- **Sales:** Stores sales IDs, product IDs, quantities sold, sale amounts, and sale dates.

## SQL Concepts Covered
- Database and table creation
- Data insertion using `INSERT INTO`
- Data retrieval using `SELECT`
- Filtering records using `WHERE`
- Sorting records using `ORDER BY`
- Limiting results using `LIMIT`
- Aggregate functions such as `COUNT()`, `SUM()`, and `AVG()`
- Grouping data using `GROUP BY`
- Filtering grouped data using `HAVING`
- Primary key and foreign key constraints
- Altering tables using `ALTER TABLE`
- Updating records using `UPDATE`
- Deleting records using `DELETE`
- Renaming tables and columns
- Filtering values using `BETWEEN`
- Calculations using SQL expressions

## Project Objectives
- Understand SQL commands and clauses.
- Create and manage relational database tables.
- Retrieve and filter data from tables.
- Perform calculations and summarize data.
- Apply primary key and foreign key constraints.
- Modify database structures and records.

## How to Run
1. Download the SQL file from this repository.
2. Open MySQL Workbench or another compatible SQL editor.
3. Execute the SQL statements in the correct order.
4. Review the query results to understand the output of each operation.

## Conclusion
This project demonstrates the application of SQL commands and clauses for database creation, data manipulation, data retrieval, filtering, sorting, aggregation, and table management.
